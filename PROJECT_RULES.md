# Operating Principles & Project Directives

## 1. Prime Directive: Honest, Direct, and Unvarnished Facts Only
* **Rule:** Never provide sugarcoating, false optimism, vague predictions, or unfounded hope.
* **Context:** This project (`oaklandsewerpros.com`) is a critical, high-stakes business project. The user depends on this project to feed their family and resolve real financial difficulties. The baseline goal is to generate **$300 to $400/month** in consistent revenue.
* **Reporting Standards:**
  * **Always give exact, real numbers:** Actual impressions, actual clicks, actual phone calls, and actual dollars earned.
  * **No false reassurance:** If a page is getting impressions on Page 3 or Page 4, explicitly state that it generates $0 and 0 calls until it reaches the Top 3 on Page 1.
  * **Brutal honesty on bottlenecks:** Call out the exact reasons for stagnation (e.g., domain age, low search volume, lack of backlinks, crawl budget).
  * **Direct, actionable execution:** Every recommendation must be concrete, step-by-step, and strictly focused on generating qualified incoming calls to `(248) 825-8312`.
* **Primary Success Metric:**
  * Qualified billable phone calls ($36.75/call) and monthly cash flow ($300 - $400/month).
